# دوائي — تطبيق أندرويد للتذكير بمواعيد الدواء

تطبيق أندرويد أصلي (Java + WebView) **بدون أي مكتبات خارجية**.
يعمل على Android 8.0 فما فوق، والتنبيه يصل **حتى والتطبيق مغلق** وبعد إعادة تشغيل الجوال.

## طريقة ١: بناء APK مجاناً عبر GitHub (بدون تثبيت أي برنامج)
1. أنشئ مستودعاً جديداً على github.com (يمكن أن يكون خاصاً).
2. ارفع محتويات هذا المجلد كما هي، بما فيها مجلد `.github` المخفي
   (من صفحة المستودع: **Add file → Upload files** ثم اسحب الملفات).
3. افتح تبويب **Actions**، وستجد أن البناء بدأ تلقائياً (من ٣ إلى ٥ دقائق).
4. عند ظهور ✅ افتح البناء، ومن أسفل الصفحة نزّل **Dawai-APK** (ملف zip بداخله `Dawai.apk`).

## طريقة ٢: Android Studio
1. **File → Open** ثم اختر هذا المجلد.
2. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
3. ستجد الملف في `app/build/outputs/apk/`.

## التثبيت على الجوال
1. انقل `Dawai.apk` إلى الجوال وافتحه.
2. اسمح بـ«التثبيت من مصادر غير معروفة» عندما يُطلب منك.
3. افتح التطبيق، أضف الدواء الأول، ثم وافق على إذن الإشعارات.
4. على جوالات Xiaomi وHuawei وOppo وSamsung: من إعدادات التطبيق اختر «البطارية» ثم **بدون قيود** حتى لا يوقف النظام المنبّهات.

## مكوّنات المشروع
| الملف | الوظيفة |
|---|---|
| `assets/index.html` | الواجهة كاملة (عربي، من اليمين لليسار) |
| `MainActivity.java` | يعرض الواجهة ويربطها بالنظام عبر `AndroidBridge` |
| `Reminders.java` | جدولة المنبّهات الدقيقة بـ `AlarmManager` |
| `ReminderReceiver.java` | الإشعار وأزراره: «تناولته» و«بعد ١٠ دقائق» |
| `BootReceiver.java` | إعادة جدولة المنبّهات بعد إعادة التشغيل أو تغيير الوقت |
